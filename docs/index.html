PhysLog

スポーツ選手・ジム利用者のための身体データ記録アプリ（iOS）

Physical（身体的な）+ Log（記録）。体重や筋トレだけでなく、 垂直跳び・50m走・握力といった競技パフォーマンスの土台になる数値を 長期的に残していけることが、一般的な筋トレ記録アプリとの違いです。

記録できるもの

  • 身体計測：体重・体脂肪率・各部位のサイズ
  • 運動能力：垂直跳び・50m走・握力などの測定値
  • トレーニング：種目ごとの重量・回数・セット数
  • コンディション：睡眠・疲労感・体調
