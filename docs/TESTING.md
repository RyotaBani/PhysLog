# 実機テスト手順とチェックリスト

## 事前に必要なもの

- Mac（Xcode 16 以降）
- iPhone と Lightning / USB-C ケーブル
- Apple ID（**無料アカウントでも実機テストは可能**）

Apple Developer Program（年12,980円）は App Store 提出時には必須ですが、**手元での動作確認だけなら無料のApple IDで足ります**。ただし無料アカウントの場合、インストールしたアプリは**7日で起動できなくなります**。期限が切れたら再度 Xcode から実行し直してください。

---

## Step 1. iPhone側の準備

### デベロッパモードを有効にする（iOS 16以降）

```
設定 → プライバシーとセキュリティ → デベロッパモード → オン
→ 再起動を求められるので再起動
```

この項目は **Mac に一度接続するまで表示されません**。見当たらない場合は先にケーブルで繋いでください。

---

## Step 2. Xcodeの設定

1. `PhysLog.xcodeproj` を開く
2. 左のファイル一覧で一番上の **PhysLog**（青いアイコン）を選択
3. **TARGETS → PhysLog → Signing & Capabilities** タブ

```
Automatically manage signing : チェックを入れる
Team                         : 自分の Apple ID を選択
                               （なければ Add an Account... で追加）
Bundle Identifier            : com.ryotabani.PhysLog
```

> `Failed to register bundle identifier` と出たら、Bundle Identifier が他の人と衝突しています。
> `com.ryotabani.PhysLog2` のように末尾を変えれば通ります。

---

## Step 3. 実行

1. iPhone を Mac に接続（初回は iPhone 側で「このコンピュータを信頼しますか？」→ 信頼）
2. Xcode 上部の実行先（デバイス選択）を **自分のiPhone** に変更
3. **⌘R**

### 「信頼されていないデベロッパ」と出たら

初回は必ず出ます。iPhone側で許可します。

```
設定 → 一般 → VPNとデバイス管理
→ デベロッパApp の自分のApple ID → 信頼
```

その後もう一度 ⌘R で起動します。

---

## Step 4. 課金のテスト

**App Store Connect への登録なしで、実機でも購入フローを試せます。**

スキームに `PhysLog.storekit` を紐付け済みなので、Xcode から実行している間はテスト購入が有効になります。実際の課金は発生しません。

購入状態のリセットは Xcode の **Debug → StoreKit → Manage Transactions** から行えます。

> 広告は AdMob SDK を追加するまで表示されません（`docs/ADS.md`）。
> 操作性の確認だけなら未追加のままで問題ありませんが、
> **広告バナーの分だけ画面が狭くなる**ため、レイアウトの最終確認時には追加してから見てください。

# 操作性チェックリスト

シミュレータでは気づけない項目に絞っています。**実際に片手で持って、親指だけで操作してみてください。**

## 入力まわり（いちばん問題が出やすい）

- [ ] 体重入力で数字キーボードが出るか（フルキーボードだと入力が面倒）
- [ ] キーボードが入力欄を隠していないか（特に「メモ」欄）
- [ ] キーボードを閉じる手段があるか（画面外タップ・スワイプで閉じるか）
- [ ] トレーニング記録で種目を4つ以上追加したとき、スクロールして入力できるか
- [ ] 小数点が入力できるか（`68.5` のような値）
- [ ] 入力途中で誤って画面を閉じたとき、データが消えて困らないか

## 片手操作

- [ ] タブバーの5項目が親指で押し分けられるか（誤タップしないか）
- [ ] 右下の「+」ボタンに親指が届くか
- [ ] グラフの期間切り替え（1ヶ月/3ヶ月/…）が押しやすいか
- [ ] 記録を消すスワイプが誤爆しないか

## 表示

- [ ] 文字が小さすぎないか（特にグラフの軸ラベル）
- [ ] ダークモードで読めるか（設定 → 画面表示と明るさ → ダーク）
- [ ] 文字サイズを大きくしても崩れないか
      （設定 → アクセシビリティ → 表示とテキストサイズ → 文字を大きく）
- [ ] グラフの線が細すぎないか
- [ ] 分析画面のぼかしプレビューが「何が得られるか」伝わる見え方か

## 動作

- [ ] 起動が速いか（3秒以内）
- [ ] デモデータを入れた状態でグラフのスクロールがカクつかないか
- [ ] 機内モードで起動しても落ちないか
- [ ] アプリを削除 → 再インストールしても落ちないか
- [ ] ホーム画面のアイコンが意図通りに見えるか

## 実際の使用シーンを再現する

ジムで使うことを想定して、以下を試してみてください。

- [ ] セット間の30秒で1種目分を入力し切れるか
- [ ] 汗ばんだ手でもタップが効くか
- [ ] 明るい屋外で画面が見えるか

| 画面 | 問題 | 優先度 |
|------|------|--------|
|      |      |        |
|      |      |        |
|      |      |        |

優先度の目安

- **高**: 入力できない・データが消える・落ちる
- **中**: 操作しにくい・分かりにくい
- **低**: 見た目の好み

高だけ直してリリースし、中と低は次のバージョンに回すのが現実的です。
