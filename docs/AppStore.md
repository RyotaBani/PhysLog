## 説明（4000字以内）

```
PhysLogは、スポーツ選手とジム利用者のための身体データ記録アプリです。

体重や筋トレの記録だけでなく、垂直跳び・50m走・握力といった「競技につながる数値」を長期的に残せることが最大の特徴です。


■ 4つのカテゴリで身体を記録

・身体測定
体重、体脂肪率、筋肉量を記録します。前回との差も自動で表示されます。

・身体能力
垂直跳び、立ち幅跳び、50m走、100m走、20mスプリント、握力、反復横跳び、シャトルラン、長座体前屈、ベンチプレスMAX、スクワットMAX、デッドリフトMAX、腕立て伏せ、懸垂など15種目をプリセットで用意。競技特有のテストは自由入力で追加できます。

・トレーニング
種目、重量、回数、セット数を記録すると、総挙上量が自動で計算されます。部位別の種目リストから検索して選べるので入力もスムーズです。

・コンディション
睡眠時間、疲労度、体調を記録。数値の伸び悩みが練習量ではなく回復不足だった、といった気づきにつながります。


■ 成長をグラフで確認

体重、体脂肪率、筋肉量、身体能力、週ごとの総挙上量、体調の6指標をグラフで表示します。表示期間は1ヶ月・3ヶ月・6ヶ月・1年・全期間から選択でき、最新値、最高値、最低値、期間中の変化量も一目で確認できます。

50m走のようなタイム種目は「短いほど良い記録」として扱われるため、自己ベストの判定や変化量の色分けが正しく行われます。


■ 目的に合わせたメニュー提案

「筋力・筋量UP」「スピード・瞬発力」「持久力UP」「体脂肪を落とす」「競技パフォーマンス」の5つの目的から選び、トレーニング歴と週あたりの実施日数を指定すると、日ごとのメニューが提案されます。

各種目にはセット数、回数、休憩時間に加えて、フォームで意識すべきポイントも添えてあります。


■ 完全無料

サブスクリプションもアプリ内課金もありません。すべての機能を制限なく使えます。
運営費をまかなうため画面下部にバナー広告を表示していますが、機能に制限はありません。


■ プライバシーに配慮した設計

・アカウント登録は不要です
・データはすべて端末内にのみ保存されます
・外部サーバーへの送信は一切ありません
・解析ツールや広告SDKは組み込んでいません

記録はCSV形式で書き出せるため、表計算ソフトでの分析やバックアップにも対応しています。


■ こんな方に

・競技力の向上を数値で確認したい選手
・シーズンを通して身体の変化を追いたい方
・ジムでのトレーニング量を管理したい方
・体重だけでなく身体能力も記録したい方
・広告や課金のないシンプルなアプリを探している方


■ ご注意

トレーニングメニューの提案は一般的なトレーニング原則に基づく参考情報です。医療上の助言を目的としたものではありません。痛みや違和感がある場合は中止し、必要に応じて専門家にご相談ください。

データは端末内にのみ保存されるため、アプリを削除すると記録も削除されます。機種変更の前にはCSV書き出しでのバックアップをおすすめします。
```

## サポートURL / プライバシーポリシーURL

`docs/` 配下の2ファイルを GitHub Pages で公開して指定します。

| 欄 | URL |
|----|-----|
| サポートURL | `https://ryotabani.github.io/physlog/support.html` |
| プライバシーポリシーURL | `https://ryotabani.github.io/physlog/privacy.html` |

**公開手順**

1. GitHub で `physlog` という名前のリポジトリを作成する
2. `docs/privacy.html` と `docs/support.html` をリポジトリ直下に置いて push する
3. Settings → Pages → Source を `main` ブランチの `/ (root)` に設定する

リポジトリ名を変える場合は、`SettingsView.swift` 内のリンク2箇所も合わせて修正してください。

## v1.0 のリリース構成

**完全無料 + バナー広告**で提出します。Pro（課金）の実装は残していますが、
`FeatureFlags.isProEnabled = false` によって導線を塞いでいるため、
App Store Connect での**サブスクリプション登録は不要**です。

| 項目 | v1.0 |
|------|------|
| 価格 | 無料 |
| アプリ内課金 | **なし**（登録不要） |
| 広告 | あり（Google AdMob バナー） |
| コンディション分析 | 無料で全ユーザーに開放 |

有料アプリケーション契約の締結も、この構成では不要です。
将来 Pro を有効化する際に必要になります。

**分析機能を無料で出す理由**：この機能が他の筋トレ記録アプリとの差別化点であり、
初期のダウンロードを取りにいくうえで最も訴求力があるためです。
また、いったん無料で提供した機能を後から有料化すると反発を招くため、
将来課金する場合はクラウド同期など**新規機能**を対象にする想定です。

## App Privacy（プライバシー質問への回答）

**広告導入により、この回答は「はい（データを収集する）」に変わります。**
広告SDKが端末識別子を取得するため、「収集しない」と回答すると虚偽申告になり、
発覚時にアプリが削除される可能性があります。

App Store Connect の「App のプライバシー」での回答:

| 質問 | 回答 |
|------|------|
| このAppはデータを収集しますか？ | **はい** |

収集するデータ種別（Google AdMob による）:

| データ種別 | 用途 | ユーザーに紐づくか | トラッキングに使うか |
|-----------|------|------------------|-------------------|
| 識別子 → デバイスID | サードパーティ広告 | はい | **はい** |
| 使用状況データ → 広告データ | サードパーティ広告 | はい | **はい** |
| 診断 → クラッシュデータ・パフォーマンスデータ | 分析 | いいえ | いいえ |
| 位置情報 → 大まかな位置情報 | サードパーティ広告 | はい | はい |

> ユーザーが入力した身体データ・トレーニング記録そのものは端末内にのみ保存され、
> 収集対象ではありません。収集されるのは広告SDKが扱う識別子等のみです。

正確な最新の申告内容は Google の公式ガイド
「AdMob における App Store のデータ収集に関する開示」を確認して合わせてください。

## ATT（App Tracking Transparency）

トラッキング用途があるため、ATTダイアログの実装が必須です。

- `NSUserTrackingUsageDescription` を `Info.plist` に記載済み
- 起動から約1.5秒後にダイアログを表示する実装済み
- 拒否された場合も非パーソナライズ広告が配信されるため収益はゼロにならない

審査では「ダイアログを出さずにIDFAを取得している」と判定されると差し戻されます。

## EEA/英国向けの同意管理（要判断）

Google は EEA・英国のユーザーに広告を配信する場合、
認定 CMP（同意管理プラットフォーム）の実装を義務付けています。

選択肢は2つです。

| 方針 | 対応 |
|------|------|
| **A. 日本のみで配信**（推奨・初回リリース向け） | App Store Connect の価格および配信状況で「日本」のみを選択する。UMP実装は不要 |
| B. 全世界配信 | Google User Messaging Platform (UMP) SDK を追加し、同意取得フローを実装する |

初回リリースは A で始め、ダウンロードが伸びてから B に移行するのが現実的です。

## 年齢制限（Age Rating）

すべての質問に「なし」を選択します。想定される結果は **4+** です。

ただし「健康/フィットネス関連のテーマ」を扱うため、以下の質問には注意してください。

| 質問 | 回答 |
|------|------|
| 医療・治療情報 | なし |
| 健康・フィットネスに関する記述 | **まれ／穏やか** |

トレーニングメニュー提案があるため、健康・フィットネスの項目のみ「まれ／穏やか」を選ぶのが安全です。それでも 4+ のままです。

## 輸出コンプライアンス

ビルド設定に `ITSAppUsesNonExemptEncryption = NO` を埋め込み済みのため、App Store Connect 側で毎回質問されることはありません。

本アプリは暗号化機能を使用していません（HTTPS通信すら行いません）。

## スクリーンショット仕様

App Store Connect で必須となるサイズは1つだけです。他サイズは自動でリサイズされます。

| デバイス | 解像度 | 必要枚数 |
|----------|--------|----------|
| iPhone 6.9インチ（15 Pro Max / 16 Pro Max） | 1320 × 2868 | 3〜10枚 |

v1.0 は iPhone 専用（`TARGETED_DEVICE_FAMILY = 1`）で提出するため、iPad 用のスクリーンショットは不要です。
生成済みのファイルは `screenshots/` にあります（5枚）。
文言や配色を変更したい場合は `tools/make_screenshots.py` を編集して再生成できます。

```bash
python3 tools/make_screenshots.py
```

### 推奨する構成（5枚）

デモデータを入れた状態でシミュレータの ⌘S で撮影します。

| # | 画面 | 添えるキャッチコピー |
|---|------|---------------------|
| 1 | ホーム | 身体の変化を、ずっと残す。 |
| 2 | グラフ（体重） | 成長を、グラフで確かめる。 |
| 3 | 記録（身体能力） | 垂直跳びも、50m走も、握力も。 |
| 4 | 記録（トレーニング） | 総挙上量は、自動で計算。 |
| 5 | メニュー | 目的に合わせた、メニュー提案。 |

**撮影手順**

1. シミュレータで iPhone 16 Pro Max を選択して実行する
2. 設定タブ →「デモデータを追加」を実行する
3. 各画面を開き、⌘S でスクリーンショットを保存する
4. 保存先はデスクトップ（既定）
