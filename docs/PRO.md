## すぐ試す

App Store Connect に登録しなくても、シミュレータで購入フローを確認できます。

```
⌘R で実行
→ グラフタブ → 右上の「分析」アイコン
→ ぼかしがかかった分析画面 →「詳しく見る」
→ ペイウォールで購入（テスト購入なので課金されません）
→ 分析が見え、広告が消えることを確認
```

スキームに `PhysLog.storekit` を紐付け済みなので追加設定は不要です。もし価格が表示されない場合は次を確認してください。

```
Product → Scheme → Edit Scheme → Run → Options
→ StoreKit Configuration: PhysLog.storekit
```

購入状態のリセットは **Debug → StoreKit → Manage Transactions** から行えます。

## 相関分析の設計

### 何を分析しているか

同じ日に記録された「コンディション」と「パフォーマンス」を突き合わせ、ピアソンの積率相関係数を計算しています。

| 軸 | 変数 |
|----|------|
| コンディション側 | 睡眠時間 / 疲労度 / 体調 |
| パフォーマンス側 | 総挙上量 / 記録済みの各身体能力 |

出力は3つです。

1. 日本語の所見（例：「睡眠時間が長い日ほど、総挙上量が高い傾向がありました」）
2. 中央値で2群に分けた平均比較（例：「7.0時間以上の日の平均は 4,820kg、それ未満は 4,310kg」）
3. 回帰直線つきの散布図

### 意図的にやっていないこと

**体重とパフォーマンスの相関は自動所見の対象から外しています。**
「体重が軽いほど記録が良い」という文章が自動生成されると、減量を煽る方向に働きかねないためです。体重の推移は従来どおりグラフタブで確認できます。

**データが8件未満のときは相関を表示しません。**
少数のデータで相関を語ると、偶然の一致を法則のように見せてしまいます。代わりに「あと何日分の記録が必要か」を案内しています。

**所見は断定しません。**
すべて「〜傾向がありました」で統一し、行動を指示する書き方は避けています。画面下部に「相関は因果ではない」旨の注意書きを常時表示しています。

## App Store Connect への商品登録

### 1. 契約情報

「ビジネス」→「有料アプリケーション契約」を締結し、銀行口座と税務情報を登録します。**これが完了していないと商品が `Product.products(for:)` で取得できません。** 審査より時間がかかることがあるので最初に着手してください。

### 2. サブスクリプショングループを作成

```
マイApp → PhysLog → 収益化 → サブスクリプション
→ サブスクリプショングループを作成: "PhysLog Pro"
```

### 3. 商品を登録

`PhysLog/Pro/ProStore.swift` の商品IDと完全に一致させてください。

| 商品ID | 種別 | 価格 | 備考 |
|--------|------|------|------|
| `com.ryotabani.PhysLog.pro.monthly` | 自動更新サブスク | ¥300 | 7日間の無料トライアル |
| `com.ryotabani.PhysLog.pro.yearly` | 自動更新サブスク | ¥2,000 | 7日間の無料トライアル・おすすめ表示 |
| `com.ryotabani.PhysLog.pro.lifetime` | 非消費型 | ¥1,500 | 買い切り |

各商品に以下が必要です。

- 表示名・説明（日本語）
- スクリーンショット（審査用。ペイウォール画面を撮ればOK）
- 価格

### 4. 小規模事業者プログラムに登録

年間売上100万ドル未満なら手数料が下がります。申請は App Store Connect の「契約」から行えます。忘れると手数料が倍近くになります。

## 審査で落ちやすい点

| 指摘 | 対策 |
|------|------|
| Guideline 3.1.2 サブスクリプション情報の不足 | 価格・期間・自動更新・解約方法をペイウォールに明記済み |
| 利用規約（EULA）へのリンクがない | Apple標準EULAへのリンクを設置済み |
| 「購入を復元」がない | ペイウォール右上と設定画面に設置済み |
| 商品が読み込めず審査不能 | 有料アプリケーション契約の締結を先に済ませる |

審査メモに以下を追記しておくと、分析機能が空に見えて差し戻される事故を防げます。

```
Pro機能「コンディション分析」は、コンディションとトレーニングを
同じ日に記録したデータが8日分以上必要です。
「設定」→「デモデータを追加」を実行すると3ヶ月分のサンプルが入り、
分析機能をすぐにご確認いただけます。
```

## 価格の考え方

初期値は月額¥300 / 年額¥2,000 / 買い切り¥1,500にしてあります。

年額が買い切りより高いのは意図的です。買い切りを「一番安い選択肢」にすると継続収益が積み上がりませんが、サブスクを嫌う層は一定数いるため受け皿としては残しています。年額を推奨表示にしているのはこのためです。

価格変更は App Store Connect 側だけで完結し、アプリの更新は不要です（コードは `Product.displayPrice` を表示しているため）。まず低めに出して反応を見る、という進め方ができます。

## 今後の改善余地

今回はトリガー出し分けを実装していません。現状のペイウォール導線は次の2つだけです。

- グラフタブ →「分析」→ ぼかし画面から
- 設定タブ → Pro セクションから

コンバージョンを上げるなら、次のような出し分けが有効です。

- 記録が通算30件を超えたときにホーム画面へバナーを出す
- 自己ベスト更新時に「この記録が出た日のコンディションを分析しますか」と提示

いずれも `ProStore.isPro` を見て出し分ければよく、既存構造のまま追加できます。
