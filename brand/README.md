# ブランド素材

`python3 tools/make_brand.py` で生成しています。
**出力は実行環境（フォント・Pillow のバージョン）に依存する**ため、
作り直す場合は環境を固定し、結果を目視で確認してから差し替えてください。

## マークの考え方

右肩上がりの棒グラフと上向き矢印を1つの形に統合しています。
以前は棒3本・線・点3つ・矢印・台座で8要素あり、ホーム画面の 60px では
細部が潰れていました。3要素に絞ることで小サイズでも形が保たれます。

色は左から青（#0087FF）→ 緑（#33C759）へ変化させ、
「積み上がって伸びる」ことを表しています。

### アプリ画面入り

実際の画面を見せたいときはこちらを使います。ロゴだけの版より訴求力がありますが、
UI を変更したら作り直しが必要です。

| ファイル | 用途 | サイズ |
|---------|------|--------|
| `app_x_1200x675.png` | X の投稿画像（左に文言・右に画面） | 1200×675 |
| `app_square_1080.png` | Instagram・Threads | 1080×1080 |
| `app_story_1080x1920.png` | ストーリー（分析画面） | 1080×1920 |

画面の描画は `tools/make_screenshots.py` を読み込んで共有しています。
App Store 用スクリーンショットと同じコードから生成されるため、見た目がずれません。

`icon_1024.png` は `PhysLog/Assets.xcassets/AppIcon.appiconset/` にも
同じものが配置され、アプリのビルドに使われます。

### 機能紹介（分析）

```
「よく眠れた日は重さが上がる」

その感覚、数字で確かめられます。

PhysLog は睡眠・疲労とトレーニング実績の関係を
自動で分析して、日本語で教えてくれます。
```

### 機能紹介（取り込み）

```
体組成計のデータ入力が面倒で続かない方へ。

PhysLog は3つの方法で取り込めます。
・Appleヘルスケア（タニタ・InBody 等と連携）
・CSV（ジムの業務用機の出力）
・写真（結果用紙やアプリ画面をOCR）

手入力した記録が上書きされることはありません。
```
